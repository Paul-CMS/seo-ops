# Home Mobile Medical - VA Worklist

**One living worklist for every VA item** · client Home Mobile Medical (homemobilemedical.com) · updated 2026-10-20 · **Progress:** 0 of 21 row(s) done

## Start here

- **What this is:** every task for Home Mobile Medical's website that a person has to do, in one list. Nothing else is needed — each row says what to do, where, how, what to type, and how to check it worked.
- **Order:** work through the sections from 1 to 6, and inside each section from top to bottom. A row's `depends_on` lists the rows that must be done first (for example, a redirect comes after its target page is published). Section 4 is published all together.
- **Who owns what:** Jonie — the `owner` column on each row. Jonie: technical and publishing. Gwen: lookups and records. Paul: decisions.
- **How to tick a row:** in the CSV set `status` to **done**, **blocked** or **deviated** (a `note` is required on every blocked or deviated row) and send it back. Check the current value first: already done → mark `done` and say `already done`; something else → do not change it, mark `blocked` and say what you found. Do not add rows.
- **After you return it:** the system checks every done row against its `done_check`. A row whose check fails comes back as `open`, with the reason in `note`.

> **Sections 3 Redirects, 4 Publish and 5 After publish come in one handover**, once every service and location page is a WordPress draft (2 row(s) waiting).
