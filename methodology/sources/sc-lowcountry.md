# Sources — South Carolina Lowcountry (Beaufort, Jasper, Charleston, Berkeley, Dorchester counties)

Rewrite 2 P6. The researcher agent looks here first for public facts (a place, a code, the trade) and cites what it
reads, with the date. Built once, reused for every client in the area. New sources are flagged (`run.py flag`) and
added by Paul in `/system-review`. Links checked 2026-10-09 unless marked otherwise. A row marked **Local context
only** is never cited for a permit, code or any regulatory fact — only official government sources are.
